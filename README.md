# FORM — Composition Studio

A standalone 3D composition editor. The Premium Applicator model and required libraries are embedded in index.html. No build step or Node.js runtime is required.

## Deploy with GitHub and Netlify

1. Upload the contents of this folder to the root of a GitHub repository.
2. In Netlify, import an existing project from GitHub and select that repository.
3. Select the main branch, leave the build command empty, and set the publish directory to `.`.
4. Deploy. Later commits to the linked branch automatically update the site.

The included netlify.toml sets the publish directory.
Uploaded packaging artwork and edits are stored only in the browser session and reset on reload.
